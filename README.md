# UseDev 🚀

Aplicativo mobile desenvolvido em Flutter para um e-commerce voltado ao público geek e de tecnologia. O projeto foi construído com foco em boas práticas de componentização, Clean Code e separação de responsabilidades.

Este projeto foi desenvolvido como parte de uma avaliação (checkpoint) prática do curso de Ciência da Computação da UNINASSAU.

## 📱 Funcionalidades

* **Catálogo de Produtos:** Visualização de itens geeks (camisetas, canecas, quadros, mousepads, etc.) utilizando cards componentizados e reutilizáveis.
* **Barra de Busca:** Sistema de pesquisa integrado na tela inicial para facilitar a localização de produtos.
* **Carrinho de Compras:** Gerenciamento da lista de itens selecionados pelo usuário.
* **Checkout e Pagamento:** Tela de pagamento estruturada e otimizada utilizando os padrões mais recentes do Material Design no Flutter.
* **Arquitetura Limpa:** Código organizado com clara separação entre a Interface de Usuário (UI), Regras de Negócio (Services) e Estrutura de Dados (Models).

## 🛠 Tecnologias Utilizadas

* **[Flutter](https://flutter.dev/):** Framework de UI para construção do aplicativo nativo.
* **[Dart](https://dart.dev/):** Linguagem de programação orientada a objetos.
